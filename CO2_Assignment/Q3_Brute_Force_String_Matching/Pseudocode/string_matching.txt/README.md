### Algorithm: Brute-Force String Matching

1. Start.
2. Read the text and the pattern.
3. Set the comparison count to zero.
4. Align the pattern with the beginning of the text.
5. Compare the pattern characters with the corresponding text characters.
6. If all characters match, report the starting position.
7. If a mismatch occurs, shift the pattern one position to the right.
8. Repeat until all possible alignments are checked or a match is found.
9. Display the match position and number of character comparisons.
10. Stop.
