### Algorithm: Brute-Force Convex Hull

1. Start.
2. Read the set of points.
3. Create an empty set of hull edges.
4. Consider every pair of distinct points A and B.
5. For every other point C, calculate its orientation relative to line AB.
6. Check whether all points lie on the same side of AB or on the line.
7. If the condition is satisfied, add AB as a hull edge.
8. Display the hull edges.
9. Plot the points and hull boundary.
10. Stop.
