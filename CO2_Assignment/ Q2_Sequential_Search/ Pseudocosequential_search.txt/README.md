### Algorithm: Sequential Search

1. Start.
2. Read the list of tool IDs and the target tool ID.
3. Set the comparison count to zero.
4. Traverse the list from the first element.
5. Compare each element with the target and increment the comparison count.
6. If the target is found, return its position and comparison count.
7. If the list ends without finding the target, report that it is not found.
8. Display the result and comparison count.
9. Stop.
