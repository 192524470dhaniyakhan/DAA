### Algorithm: Brute-Force Closest Pair

1. Start.
2. Read the coordinates of n points.
3. Set the minimum distance to infinity.
4. For each point i, consider every point j after i.
5. Calculate the Euclidean distance between points i and j.
6. If the distance is smaller than the minimum distance, update the minimum distance and closest pair.
7. Continue until every unique pair has been examined.
8. Display the closest pair, minimum distance, number of pairs examined, and number of distance calculations.
9. Stop.
