
ALGORITHM 1: SELECTION SORT

1. Start.
2. For each position i from 0 to n-2:
   a. Assume the element at i is the minimum.
   b. Compare it with every remaining element.
   c. Find the position of the smallest element.
   d. Swap it with the element at i if necessary.
3. Return the sorted array.
4. Stop.


ALGORITHM 2: BUBBLE SORT

1. Start.
2. Repeat passes through the array.
3. Compare adjacent elements.
4. If the left element is greater, swap them.
5. If a complete pass has no swaps, stop early.
6. Return the sorted array.
7. Stop.


ALGORITHM 3: INSERTION SORT

1. Start.
2. Consider the second element as the key.
3. Compare the key with elements to its left.
4. Shift larger elements one position right.
5. Insert the key into its correct position.
6. Repeat until all elements are processed.
7. Return the sorted array.
8. Stop.
